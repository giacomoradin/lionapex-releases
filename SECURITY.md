# Politica di Sicurezza & Segnalazione Vulnerabilità

La sicurezza, la privacy e l'integrità dei dati degli utenti di **LIONApex** sono una priorità assoluta.

---

## Versioni Supportate

| Versione | Supportata |
| :--- | :--- |
| `0.1.x` (Corrente) | :white_check_mark: Sì |
| `< 0.1.0` | :x: No |

---

## Come Segnalare una Vulnerabilità

Se hai individuato una vulnerabilità di sicurezza, una falla nel sistema crittografico o un problema di esposizione dati:

1. **NON aprire una Issue pubblica**.
2. Invia una segnalazione privata via **GitHub Security Advisories**:
   - Vai alla scheda [Security Advisories](https://github.com/giacomoradin/lionapex-releases/security/advisories) del repository.
   - Clicca su **"Report a vulnerability"**.
3. Includi nella segnalazione:
   - Descrizione dettagliata della vulnerabilità.
   - Passaggi riproducibili (Proof of Concept).
   - Impatto potenziale e sistema operativo di test.

Risponderemo entro **48 ore** con una valutazione e un piano per il rilascio di una patch correttiva.
